## Executive Summary

SegmiQ is a software platform built for how trade and service businesses in Africa actually win work. Construction, solar, roofing, electrical, and landscaping companies rely on WhatsApp, Facebook ads, and word-of-mouth — not email sequences and dialers. SegmiQ connects that reality to a single system: capture every enquiry, respond fast, coach the sales team, close deals, and document completed work.

The platform is sold as two complementary products on shared infrastructure:

- **SegmiQ CRM** — lead capture, scoring, routing, WhatsApp automation, quotations, billing, and performance intelligence
- **SegmiQ Cloud** — project documentation, public portfolios, field photo capture, and lead capture from completed work

SegmiQ is designed for **direct sales to trade businesses**, **marketing agencies managing multiple clients**, and a **partner channel** with recurring commission. It is built WhatsApp-first, Africa-native, and vertical-specific — not a generic CRM adapted for the region.

## The Problem

Service businesses across Africa lose revenue in three predictable ways:

### 1. Leads disappear before anyone responds

Enquiries arrive on WhatsApp, Facebook, personal phones, and walk-ins. Without a central system, response times stretch to hours. Research consistently shows leads are **9× more likely to qualify** when the first response lands within five minutes — yet most trade businesses miss that window.

### 2. Pipeline walks out the door with the salesperson

When a rep leaves, they take contacts, conversation history, and relationships stored on personal devices. The business starts from zero. There is no permanent record of calls, messages, status changes, or handover context.

### 3. Completed work stays invisible

Strong projects live in camera rolls and chat threads instead of professional portfolios. Prospects cannot see proof of quality. Marketing spend generates leads, but the business cannot convert trust into contracts at scale.

Generic CRMs built for US software teams do not solve this. They assume email workflows, per-seat SaaS pricing on cards, and sales processes that do not match how African trades close deals.

## The SegmiQ Solution

SegmiQ follows the path trades actually sell:

**Enquiry → Score → Route → Confirm → Coach → Quote → Document → Win**

| Stage | What SegmiQ does |
|-------|------------------|
| **Capture** | Conversational forms, Facebook Lead Ads, portfolio enquiries, WhatsApp confirmations |
| **Score** | Rules-based scoring on all plans; AI intent scoring (0–100) on Growth and Scale |
| **Route** | Magic-link assignment to the right rep via WhatsApp — no login friction |
| **Confirm** | Branded instant confirmation so prospects know they reached a real business |
| **Coach** | Daily AI coaching per rep; weekly manager digests; stale-lead recovery |
| **Convert** | One-tap send of portfolios, pricing packages, documents, and quotations |
| **Document** | SegmiQ Cloud stores project photos, milestones, and public profiles |
| **Learn** | Win analysis, performance intelligence, audience segments for retargeting |

**Three outcomes the platform is built around:**

- **9×** — higher conversion when first response is within five minutes
- **0** — leads, history, or relationships lost when a salesperson leaves
- **1** — system from first enquiry to recorded win

## Platform & Technology

SegmiQ is a modern multi-tenant SaaS platform. The following overview is intended for technical due diligence — partners and investors assessing scalability, integration depth, and engineering maturity.

### Architecture

```
┌─────────────────────────────────────────────────────────────┐
│  Client surfaces                                            │
│  Web app · Sales Android app · Field Android app · Public  │
│  profiles · Lead forms · Proposals · Quotes                 │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  Next.js application (Vercel)                               │
│  ~225 API routes · NextAuth · Middleware (auth, billing)    │
│  Cron jobs (SLA checks, coaching, campaigns, digests)       │
└──────┬──────────────┬──────────────┬──────────────┬─────────┘
       │              │              │              │
   Supabase       Cloudflare      Meta WhatsApp   Anthropic
   PostgreSQL     R2              Facebook Ads    Claude AI
   + Storage                      Resend Email
```

### Tech stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS |
| Mobile | React + Vite + Capacitor 7 (Android) |
| Auth | NextAuth.js v4 |
| Database | Supabase (PostgreSQL), 80+ schema migrations |
| File storage | Supabase Storage (logos, attachments) + Cloudflare R2 (project media) |
| Email | Resend |
| Messaging | Meta WhatsApp Cloud API |
| AI | Anthropic Claude (scoring, coaching, briefings, win insights) |
| Deployment | Vercel |
| Background jobs | Vercel Cron + GitHub Actions |

### Key integrations

| Integration | Role |
|-------------|------|
| **Meta WhatsApp Cloud API** | Lead confirmations, rep assignment, coaching, campaigns, two-way inbox |
| **Facebook Lead Ads / Marketing API** | Lead ingestion, ad accounts, campaign management |
| **Meta audience export** | CSV segments for retargeting |
| **Cloudflare R2** | Scalable project media storage |
| **Anthropic Claude** | AI intent scoring, daily coaching, weekly insights, form intelligence |

### Multi-tenancy

- Each **client** (service business) is an isolated tenant
- **Users** belong to a client with roles: Agency Admin, Client Manager, Salesperson
- Agency admins can manage and support multiple client tenants
- Subdomain routing serves public portfolio profiles per business
- Billing suspension gates access automatically when subscriptions lapse

### Data domains (database)

The platform schema covers: leads and pipeline, call logs, forms and landing pages, Facebook OAuth and webhooks, project media and milestones, lead scoring and intelligence, subscriptions and manual billing, quotations, customer hub contacts, WhatsApp inbox and qualification, marketing campaigns and journeys, agency proposals, and performance analytics.

### Security & compliance

- Role-scoped portals with middleware-enforced access
- Full audit trail on lead timelines
- Consent management in Marketing Hub
- Terms of Service and Privacy Policy published at segmiq.com/legal
- Account creation by invitation; agency-managed onboarding
